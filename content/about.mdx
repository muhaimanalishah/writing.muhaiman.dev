# About

Welcome to this personal writing space. This website is built with a singular priority: providing a calm, legible, and uncluttered reading environment for essays and reflections.

## Philosophy

The web was originally conceived as a medium for hyperlinked documents—a global library where words and ideas took center stage. Over time, many platforms added layers of friction: trackers, popups, paywalls, and heavy javascript payloads.

This site is an intentional step back toward simplicity:

* **Content First**: Every design decision—from typography sizes to line-heights—serves the reading experience.
* **No Dark Patterns**: No tracking scripts, no newsletter popups, no intrusive banners.
* **Durable & Open**: All writing is authored in standard MDX and rendered cleanly into static HTML.

## Tech Stack

This website is built with modern, minimal tooling:

* **Next.js** for static generation and server components.
* **MDX** for structured, expressive markdown content.
* **Tailwind CSS** for tokenized, responsive typography and theme support.
* **shadcn/ui** for accessible primitives and semantic components.
